# Your editor handbook

Welcome to the editorial team at **Northwind Stories**, our fictional travel journal.

Use the navigation to find a guide, or start with [writing a post](posts/create.md).
The handbook is stored as Markdown alongside this testsite. It is displayed by Handbook, not stored as Umbraco content.

## Before you publish

- Give the page a descriptive title.
- Check the text and image alternatives.
- Open the preview and follow the links.
- Ask an editor to publish if you have a Writer account.

See the [publishing workflow](publishing/workflow.md#approval-flow).

## Explore the demo

The Posts folder has its own introduction. The Publishing folder demonstrates an automatically generated overview.
